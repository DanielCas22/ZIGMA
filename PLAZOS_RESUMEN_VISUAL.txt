📌 ¿QUÉ SE IMPLEMENTÓ?
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Se agregó la capacidad de distribuir conceptos adicionales (devengos y descuentos) 
en múltiples períodos (quincenas o meses), permitiendo al administrador:

  • Adicionar un concepto por $200,000 y distribuirlo en 2 quincenas
  • Adicionar un descuento por $600,000 y pagarlo en 3 meses
  • Ver la distribución automática con vista previa en tiempo real
  • Editar y administrar los plazos de forma intuitiva

TABLA NUEVA: conceptos_adicionales_plazos
└─ Almacena cada período de pago/descuento

    id (PK)          → Identificador único
    concepto_id (FK) → Referencia al concepto
    periodo_numero   → 1, 2, 3... (número secuencial)
    valor_periodo    → Monto a pagar en ese período
    tipo_periodo     → 'quincena' o 'mes'
    estado           → 'pendiente', 'pagado', 'cancelado'
    fecha_creacion   → Cuándo se creó
    fecha_actualizacion → Última actualización

COLUMNAS NUEVAS: conceptos_adicionales_prestaciones
    total_plazos     → Cantidad de períodos (default: 1)
    tipo_plazo       → 'quincena' o 'mes'
    tiene_plazo      → TRUE/FALSE (flag de activación)

ConceptosAdicionalesModel.php

┌─────────────────────────────────────────────────────────────────────────────┐
│ agregarConcepto($emp_id, $concepto, $desc, $valor, $usuario,               │
│                 $total_plazos=1, $tipo_plazo='quincena')                    │
├─────────────────────────────────────────────────────────────────────────────┤
│ Crear concepto con soporte a plazos                                         │
│ Si $total_plazos > 1, automáticamente crea los registros de plazo           │
│                                                                              │
│ EJEMPLO:                                                                     │
│ $modelo->agregarConcepto(4, 'Bonificación', 'Bono Q4', 300000,            │
│                          'admin', 3, 'quincena');                           │
│ → Crea concepto + 3 registros de plazo de $100,000 cada uno                │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│ crearPlazos($concepto_id, $valor_total, $total_plazos, $tipo_plazo)        │
├─────────────────────────────────────────────────────────────────────────────┤
│ Crea N registros de plazo distribuyendo equitativamente el valor            │
│                                                                              │
│ EJEMPLO:                                                                     │
│ $modelo->crearPlazos(5, 600000, 2, 'mes');                                 │
│ → Crea 2 plazos de $300,000 cada uno                                        │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│ obtenerPlazos($concepto_id)                                                 │
├─────────────────────────────────────────────────────────────────────────────┤

┌─────────────────────────────────────────────────────────────────────────────┐
│ obtenerConceptoConPlazos($concepto_id)                                      │

│ RETORNA:                                                                     │

│   'id' => 5,                                                                │
│   'concepto' => 'Bonificación',                                             │
│   'valor' => 300000,                                                        │
│   'tiene_plazo' => true,                                                    │
│   'total_plazos' => 3,                                                      │
│   'plazos' => [                                                             │

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

PASO 1: Acceder al módulo
  • Total Devengado → Hacer clic en celda "Otros"
  • Total Deducido → Hacer clic en celda "Otros Descuentos"

PASO 2: Llenar formulario
  ├─ Concepto: Nombre del beneficio/descuento
  ├─ Valor: Monto total en pesos
  └─ Descripción: Detalles adicionales

PASO 3: Configurar plazos (OPCIONAL)
  ├─ ☐ Marcar "¿Distribuir en plazos?"
  ├─ Seleccionar tipo: Quincena o Mes
  ├─ Definir cantidad: 2 a 12 períodos
  └─ Observar cálculo automático

PASO 4: Guardar
  └─ Click en "Agregar Concepto" o "Agregar Descuento"

PASO 5: Verificar
  ├─ Ver en tabla con badge de plazos
  ├─ Ejemplo: "3x quincena"
  └─ Eliminar si es necesario
